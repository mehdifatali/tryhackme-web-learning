# Web Application Overview


Let's imagine a website as a planet. We can think of visiting this planet as browsing the web using a web browser.

Of course, just like a planet, a website has two sides: **Front-end and Back-end.**

The Front-end is like the surface of a planet. It is the part that we can see.

## Front-end has three main parts: HTML, CSS, and JavaScript.

**HTML:** Think of HTML as the DNA of simple organisms living on a planet. It tells us where links, images, and other elements are located. It also defines the structure of the website and how everything should be organized.

**CSS:** Now, design comes into the picture. CSS controls the appearance of the website, such as text, font styles, colors, and layout.

**JavaScript (JS):** Think of JavaScript as the computer chip or the human brain of the website. It makes the website interactive. Users can make choices, perform actions, and the website can respond to them.

## Back-end

**Back-end:** This is where the database is located. It stores information and allows us to change or update it.

You can imagine it as the countries and cities on our planet's map, where different information is stored and managed.

## Infrastructure

**Infrastructure:** This includes servers, storage, application servers, and other components that help the website work.

Think of it as the basic systems and facilities that make our planet function.

## WAF (Web Application Firewall)

**WAF:** This stands for Web Application Firewall. It helps protect a website from malicious web traffic and suspicious activity.

Imagine it as the atmosphere layer of our planet, which helps protect it from external threats.
